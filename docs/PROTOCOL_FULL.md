# Протокол основных экспериментов

Зафиксирован до основных запусков. Пилот EMA уже известен и не включается в
основную оценку. Новые seed: 20000–20029. Настройка по ним запрещена.

Цели: exp(x)-1 (глубина 2), ln(x), exp(e-x), e-exp(x) (глубина 3).
Обучение: 40 точек [0.5,2]. Проверка: 301 точка [0.503,1.997].
Экстраполяция: 301 точка [2.01,2.5]. Успех: max error < 1e-8 на обеих
проверочных сетках, вычисления без защитного ограничения exp/log.
Выбор кандидата производится исключительно по обучающей ошибке.

Основное сравнение: IR (3 независимых старта), RF (3 последовательных прохода
с переносом финальных логитов и шумом 0.5, 0.25), каждый с EMA 0 или 0.99.
Каждый проход 1000 эпох; ранняя остановка по успеху отключена. Остановка при
нечисловой потере регистрируется; фактические эпохи публикуются.
Первый проход у всех вариантов имеет одинаковый seed. Adam сбрасывается между
проходами. Это продолжение оптимизации, вдохновлённое TRM, не обучение TRM.

Бассейн: margin=4, k=0,1,3; 1000 эпох, без EMA, те же 30 seed и четыре цели.
Это диагностический эксперимент с известным ответом, не метод поиска.
Холодный контроль — первый проход IR без EMA.

H1: повреждение старта уменьшает вероятность восстановления (k=0 против k=3).
H2: EMA улучшает IR при одинаковом бюджете.
H3: RF улучшает IR при одинаковом бюджете.
Гипотезы оцениваются отдельно по целям, без заявления универсального эффекта.
95% интервалы Уилсона для долей, парный bootstrap 10000 выборок для разностей.
Интервалы описательные, без поправки на множественные сравнения; выводы
разведочные. 30 seed недостаточно для уверенного обнаружения малых эффектов.
Дополнительный контроль: полиномиальная регрессия степени 5 на тех же данных.
Точное структурное совпадение и численное восстановление учитываются отдельно.
