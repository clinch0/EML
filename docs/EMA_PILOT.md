# Первичный эксперимент EMA

Источник чисел: `benchmarks/results/ema_smoke.csv`, реальный запуск 2026-11-05.
Код эксперимента: коммит 6722f5f. Python 3.12, PyTorch 2.14.0+cpu.
Глубина 3, 2000 эпох, seed 10000–10004, beta 0 и 0.99.
Обучение: 40 точек [0.5, 2]. Проверка: 301 точка [0.503, 1.997].
Это интерполяционная проверка, не экстраполяция и не доказательство тождества.

- exp(x): 4/5 успешных восстановлений без EMA и 4/5 с EMA.
- ln(x): 0/5 без EMA и 0/5 с EMA.
- Суммарное измеренное время обучения: 75.76 секунды на 20 запусков.

На этой малой выборке преимущества EMA не наблюдается. Этого недостаточно,
чтобы утверждать эквивалентность методов или опровергать гипотезу в целом.
Расширение эксперимента должно включать больше целей и seed, парные интервалы
разности долей и отдельную проверку вне обучающего диапазона.

Проверки: 93 pytest-теста пройдены; ruff check и format --check пройдены.
Одно ожидаемое предупреждение теста о распространении NaN в safe_log.

Воспроизведение из корня репозитория после установки `pip install -e ".[dev]"`:

```shell
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
python benchmarks/ema_smoke.py
```

Текущий этап включает EMA, тесты и пилот. Итеративное исправление деревьев,
обучаемый корректор и окончательный текст курсовой ещё не реализованы.
