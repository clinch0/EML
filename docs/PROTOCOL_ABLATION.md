# Дополнительный контроль после основной серии

После наблюдения преимущества RF на ln(x) назначена новая разведочная серия.
Результат основной серии известен; это не независимая предрегистрация исходной гипотезы.
Seed 30000–30029, только ln(x), EMA выключено. Сравниваются IR, RF,
RF0 (та же процедура без добавления шума), LONG (один проход 3000 эпох).
IR/RF/RF0 имеют три прохода по 1000 эпох. LONG имеет одно расписание температуры
с 1500 мягкими эпохами и 1500 эпохами ужесточения. Критерий выбора и проверки прежний.
Контроль отделяет предложенную процедуру от простого увеличения длины обучения.
RF0 и RF отличаются только шумом; LONG отличается также числом сбросов Adam
и температурного расписания, поэтому эти два механизма отдельно не идентифицируются.
Выбор только одной функции ограничивает переносимость выводов.
