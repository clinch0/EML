# Проверка результатов курсовой

Основная серия: 1800 строк, 840 эпизодов, 0 досрочных остановок; бюджет IR/RF 3000 эпох, диагностика 1000. Все 240 пар первых проходов IR/RF совпадают по seed, дереву, потерям и числу эпох.

Независимые seed дополнительной серии: 30000–30029. 300 строк, 120 эпизодов, по 3000 эпох на эпизод. Всего 2100 проходов без пилота.

Успех означает ошибку менее 1e-8 на двух проверочных сетках при вычислении дерева без ограничений safe_exp/safe_log. Выбор кандидата выполнен по обучающей ошибке. Для логарифма 12 из 20 успешных RF эпизодов основной серии выбрали E(x,E(E(x,x),1)); для x>0 это ln(x).

Результаты не доказывают универсальность: exp(e-x) не восстановлена ни одним холодным методом, EMA не улучшила IR, отдельный вклад шума не установлен. Для RF на ln(x) наблюдалась изменчивость 20/30 и 10/30 на двух наборах seed.

Протокол основной серии: bb45d5a; исполняемый код основной серии: 2f97a4c; протокол и код дополнительного контроля: 6ff018c. Возобновление дополнительной серии сохраняет ранее готовые CSV; отметка resumed есть в meta.json.

Итоговые проверки: 99 pytest-тестов пройдены, одно ожидаемое предупреждение о NaN в тесте safe_log; ruff check и format --check пройдены.
